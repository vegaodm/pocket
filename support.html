Getting started

Do I need another app?

Yes. Pocket Assistant does not include a language model. Install Pocket LLM Chat on the same iPhone and load a model there. In Pocket Assistant, open Settings → Assistant provider and pick “Pocket LLM Chat”. Both apps must be signed by the same developer so they can share the hand-off folder.

Which model should I use?

LFM3 1.7B is the recommended model: it follows the structured answer format reliably, including dates in your local timezone. Bonsai 2B is supported and uses much less memory, but it skips the structured part more often; Pocket Assistant then falls back to reading your message directly, so records are still saved — you just get no written summary.

How should I phrase a message?

One thing per message works best:

  • “Remind me to send the invoice tomorrow at 9 AM”
  • “I spent 68 CNY on lunch with the team”
  • “Meeting with Tom on Friday at 9 AM about the mobile release”
  • “Idea: a weekly review every Friday afternoon”

A paragraph that mixes a meeting, a person and an expense is harder for a small model and produces rougher records.

Common questions

Why does the app jump to Pocket LLM and come back?

iOS allows only one app to be in the foreground, and the model lives in Pocket LLM. Pocket Assistant writes your message to a shared folder, opens Pocket LLM, waits for it to finish, and Pocket LLM hands the reply back. Pocket Assistant then updates the bubble. Pocket LLM shows a short “Generating a reply…” screen during that hand-off instead of its own chat history.

The reply says it was saved but the model wrote nothing

That is the fallback: the model did not return a usable structured answer, so Pocket Assistant read your own message and saved the record itself. Nothing is lost; the record is marked for review in Records.

What is the free limit?

50 records. Reading, searching, editing and exporting are always free; the cap only applies to new records. One one-time purchase removes it, with no subscription.

I bought the unlock on another iPhone

Open Settings → Restore Purchases while signed in with the same Apple Account, or use the Restore button on the unlock screen.

Where is my data? Can I back it up?

Everything is in a local database on your iPhone; there is no account and no cloud copy. Use Settings → Export backup to write a JSON file wherever you like, and Import backup to restore it on another device.

How do I delete everything?

Settings → Erase all data removes every record, message and pending request from the device immediately. Deleting the app also removes its data.

Troubleshooting a request that never finishes

If a bubble stays on “Waiting for Pocket LLM”, check in this order:

  • Pocket LLM is installed and a model is loaded (not only downloaded).
  • Settings → Assistant provider is set to Pocket LLM Chat and “Shared storage” reads Ready.
  • Both apps were updated from the same developer account, then relaunch both.
  • After 120 seconds the bubble offers Check result and Retry; a retry gets a fresh request.
